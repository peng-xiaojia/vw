# 桌面能力与验收范围

日期：2026-10-15。当前本地版本为 0.1.0；本表区分实际功能与正式发行验收，不以早期阶段编号表示全部完成。

## 实际支持

| 内容 | 查看 | 编辑 / 限制 |
| --- | --- | --- |
| TXT/LOG、SH/BAT/CMD/PowerShell、JS/TS/Python/Rust 等代码、INI/TOML/CFG | 按需分页、CodeMirror 高亮、行号和自动换行 | 文本快照范围内编辑；显式选择编码、LF/CRLF/CR；默认保留换行格式 |
| Markdown、JSON/JSONL、CSV/TSV | 结构预览、搜索；格式支持时提供目录 | 文本编辑，保存后刷新模型；保真条件不满足时降级 |
| HTML/HTM | 独立网页展示，保留原 CSS、图片、字体、本地脚本交互及目录内子页面导航 | 小文件可编辑并展示当前草稿；只读大文件也可展示（单资源最多 64 MiB）；网页隔离于应用 DOM / IPC，不开放跨目录、远程资源、表单提交与浏览器存储 |
| 二进制 | 按需十六进制分页；任何文件可另开二进制标签 | 只读；原查看标签及草稿保留 |
| 文件夹 | 文件树按需展开、刷新、上一级 | 点击文件打开；目录切换保留当前文档 |
| ZIP | 成员列表、双击预览、导出副本 | 成员只读，不声称写回归档 |
| PNG/JPEG/GIF/WebP/BMP | 通过句柄绑定的受控资源显示 | 只读；动画和专业图像处理不在范围内 |
| PDF | Windows 本地逐页 PNG 渲染、页目录 | 只读；最多 512 MiB / 10000 页；暂不支持文本搜索 |
| DOCX | 段落、标题、文本表格、搜索 | 只读内容预览，非 Word 排版还原 |
| XLSX | 工作表顺序、稀疏表格、共享字符串、保存的公式缓存值 | 只读；不计算公式；单表最多 500 行 / 128 列，最多 128 表；全文件预览最多 65000 单元格 / 16 MiB 文本 |
| PPTX | 幻灯片顺序、标题、文本、文本表格 | 只读内容预览，最多 500 页；不还原动画、图表及幻灯片排版 |
| Parquet | 外置插件参考实现 | 需独立安装 sidecar；不把参考模板等同内置桌面功能 |
| 旧版 DOC/XLS/PPT | office_oxide 提取段落、标题、列表、表格等正文 | 只读内容预览，非 Office 原版排版；输入最多 32 MiB；损坏、加密或解析器不支持的文档可用二进制查看 |
| 音视频、矢量 Canvas | 未交付专用预览 | 未知文件可走 hex 兜底 |

Office 解压预算：最多 4096 个成员、256 MiB 总解压量、单个 XML 最多 32 MiB，并限制 XML 深度和节点数。共享字符串在复制前核对输出文本预算。

## 桌面交互与发布

公共编辑菜单提供格式化（Shift+Alt+F）、查找（Ctrl+F）、替换与全部替换（Ctrl+H）；全部替换支持单次撤销。视图菜单控制行号与自动换行（Alt+Z），作用于源码及文本预览。状态栏分开提供「重新解码」和「保存编码」，支持 UTF-8 / BOM、UTF-16 LE/BE、GBK、GB18030、Shift-JIS、Big5、Windows-1252。不能表示的字符拒绝保存；所有保存仍执行插件校验、冲突检测、备份和原子写入。

格式化由插件声明与实现：JSON/JSONL 使用插件内部的空白排版，保留重复键、键顺序和数字字面量；JS/TS、HTML、Markdown、CSS/SCSS/Less、YAML 使用内置离线 Prettier Worker。SH/BAT、Python、Rust 等尚未注册格式化器，入口自动禁用；格式化只改变草稿，不自动保存。插件扩展接口见 [能力注册](plugin-capabilities.md)。

文档区提供多文件标签，打开文件对话框支持多选，文件树、拖放和外部传入的多个路径依次新增标签。重复路径激活已有标签；每个标签独立保存草稿、源码/展示模式、搜索、阅读位置和章节折叠状态。HTML 页面隐藏时保留原 frame，子页面位置及脚本状态随标签保留。Ctrl+Tab / Ctrl+Shift+Tab 切换，Ctrl+W、标签关闭按钮及鼠标中键关闭；退出前检查所有标签中的未保存草稿，取消退出时保留全部标签。

HTML 原页通过 `vw-preview` 独立协议与无同源权限的 sandbox iframe 展示；每个句柄只授权当前网页文件夹内的网页资源，随机挂载令牌随关闭撤销，并核对 URL 解码、扩展名、canonical 路径与 64 MiB 资源预算。网页的字体、间距及配色由原 CSS 决定，HTML 展示内 Ctrl+滚轮缩放整页，源码仍使用应用字体设置。服务端 API、外部 CDN、登录存储及站点根路径等浏览器依赖不能保证等同独立浏览器。

顶部使用 Tauri 无装饰窗口和单行网页标题/菜单栏，文件操作收进「文件」菜单，编辑/预览位于「编辑」菜单；移除手输地址栏。左侧默认仅显示图标栏，文件与搜索各自展开单一面板；文档目录位于阅读区右侧，支持标题层级的单项折叠、全部折叠/展开。Markdown 与 HTML/HTM 在文档标题行提供源码/展示切换；Markdown 使用同一个 Rust 解析器展示未保存草稿。阅读区与源码编辑区支持 Ctrl+鼠标滚轮调整阅读字号。文件树使用 Lucide 的文件夹和文件类型图标，打开外部文件时定位所在目录，Windows 路径隐藏内部扩展前缀。可编辑 TXT 默认进入编辑模式。原生拖放监听当前 WebView，进入显示提示、松开或离开清除提示。文件选择、树点击、拖放、启动参数和再次打开共用文档路由及未保存保护。

插件中心从「插件 → 插件中心」或左侧拼块图标进入。显示真实内置/已安装信息；支持格式/名称/ID 筛选、GitHub Releases 与本地 .vwpkg 安装、卸载外部插件。SHA-256 校验和 manifest 权限确认发生在安装前；包的路径、重复条目、符号链接和实际解压大小受限，暂存后提交。GUI/CLI 共用安装和卸载实现。当前没有中央商店，不兼容 DBX .dbxp；安装/卸载后重启生效。普通进程的权限声明不是操作系统沙箱。

安装版默认使用用户可写的数据目录；便携标记启用相邻缓存目录并在不可写时回退。GUI 使用 Windows GUI 子系统，sidecar 启动不创建控制台。首次安装时注册 24 种格式的「打开方式」；用户可从「文件 → 关联格式」逐项勾选，并打开 Windows 默认应用设置。程序不写受保护的 UserChoice；已保存的勾选结果在升级安装时保留。便携版也可主动注册，但不会覆盖另一份 vw 的注册。

受限开发工作区可能给生成 EXE 继承 Low 完整性标签，进程因此无权写普通 HKCU 注册表。便携包应解压到下载等普通用户目录运行，安装包也应从普通目录启动；不需要修改系统注册表权限。设置入口优先打开系统 URI，失败时用系统目录中的 Explorer 激活同一 URI。关联写入采用所需的读写权限，并提供具体失败步骤。

Windows 构建输出位于 `dist/windows/`：`portable/vw-app.exe`、`vw-windows-portable.zip`、`vw_0.1.0_x64-setup.exe`、`manifest.json` 和 `SHA256SUMS.txt`。清单记录代码版本、未提交状态、锁文件摘要与产物摘要。签名脚本支持本机证书与 VSign 云签名；正式签名需要自己的证书/账号，当前本地产物未签名。配置见 [Windows 签名](windows-signing.md)。

## 验证记录

前端控制器、渲染安全、目录树、拖放、菜单、标签与编辑状态回归共 53 项通过。真实 Chromium DOM 检查通过目录树批量折叠、滚轮字号、Markdown 草稿展示、HTML 原样式及隔离、伪造外链拒绝和多标签操作。真实 WebView2 对比用户原型的 CSS、Logo、字体与卡片布局，并通过本地子页面导航及标签位置保留，详见 [HTML 与标签验收](reviews/2026-10-15-html-tabs-validation.md)。完整 Rust 工作区测试通过。本轮编辑、编码转换与 Office 验证见 [编辑功能验收](reviews/2026-10-15-editor-validation.md)。独立代码审查修复了退出菜单权限缺失和 ZIP 实际解压量检查；此前 Office 审查修复保持有效。

工作区测试与 Windows 打包在正常 Windows 权限下执行；受限执行环境无法 canonicalize 缓存的 Tauri 文件，不能以该环境的权限失败作为正常用户环境的产品结论。当前菜单与插件中心验证见 [交付验证](reviews/2026-10-14-menu-plugin-validation.md)，此前格式预览与拖放验证见 [前轮记录](reviews/2026-10-14-desktop-completion-validation.md)。

未执行干净机器安装、升级、卸载及 SmartScreen 声誉验收，也未提供代码签名证书。原生事件冒烟通过 WebView 事件目标注入与真实 IPC 验证链路；操作系统鼠标拖拽还应在正常桌面环境人工复核。
