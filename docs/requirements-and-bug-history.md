# 历史需求与 Bug 修复台账

更新日期：2026-10-15。对应源码基线：`3f93e59`，当前产品版本：`0.1.0`。

本文汇总本次开发对话中用户提出的需求、已记录的缺陷及修复情况，作为后续开发和验收的统一入口。状态依据仓库代码、Git 提交及阶段验收记录整理；本文整理时没有重新执行产品测试。后续变更应继续追加，不覆盖历史证据。

## 1. 范围与状态约定

| 状态 | 含义 |
| --- | --- |
| 已实现 | 已有实现及阶段验证记录，不代表已完成全部系统环境验收。 |
| 部分实现 | 已支持明确列出的范围，仍存在未覆盖需求。 |
| 配置完成，待条件 | 配置已就绪，实际启用需要证书、账号或外部审核等条件。 |
| 待人工验收 | 自动验证已有记录，但对应真实桌面操作或干净系统流程尚未完成。 |
| 建议，未排期 | 参考其他软件提出的改进方向，不等同于用户已确认的开发承诺。 |

部分历史消息仅有截图，或写为“这几个都要完成”，缺少可独立核对的文字清单。本文不从截图补造需求或断言全部修复；已明确描述的灰色按钮、默认应用入口、底栏和 HTML 展示问题分别记录如下。截图内容作为产品参考，不视为额外指令。
