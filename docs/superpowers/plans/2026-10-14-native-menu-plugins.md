# 原生菜单、侧栏和插件中心

沿用用户已授权的现有开发，并按截图调整。菜单使用 Tauri/muda 原生组件；侧栏参考 VS Code Activity Bar 的点击展开/再次点击收起。图标采用 Lucide（ISC）。插件中心参考 DBX 的分区和安装前校验，但遵循当前设计 §7.3/§8：manifest v1、stdio JSON-RPC、按平台 `.vwpkg`、SHA-256、无中心 registry，不兼容 `.dbxp`。

1. 将 CLI 插件管理抽取到 vw-std，共用下载、校验、安装。安装前展示 manifest 权限；校验所有 ZIP 路径和大小，暂存后提交，失败不留下半成品。已安装列表以真实 manifest 和当前加载状态为依据。
2. 原生菜单：文件（打开/文件夹/保存/导出/关闭/退出）、编辑（编辑/预览）、视图（侧栏/文件/目录/搜索）、插件（插件中心）、帮助（关于）。保留原有文档控制器和草稿保护。
3. 默认收起导航区，只显示图标栏；文件树加文件夹和类型图标。插件中心提供 GitHub Releases 与离线包安装、已安装清单、卸载、路径/协议信息。安装与卸载后提示重启生效。
4. 验证插件校验和失败恢复、UI 交互、原生 IPC 与菜单状态，审查后生成 Windows 发布产物。
5. 签名检查：本机 DSH/DBX 均 Valid，vw 未签名，本机无代码签名私钥。准备本机证书或 VSign 云签名配置；不能用其他软件公开证书代替私钥，也不以自签证书或移除下载标记冒充正式签名。
