# 公共编辑功能与插件能力实现计划

**目标：** 在现有多标签查看器上扩展代码文件、格式化、编码与换行操作、替换和 Office 内容预览。

**架构：** 公共框架只展示和调度能力；格式插件声明查看、编辑、目录、格式化支持，并提供格式实现。CodeMirror 负责编辑交互，Prettier 为声明支持的内置格式提供格式化。编码通过共享无损编解码层处理，保留冲突检测与原子保存。

- [x] 当前成果先提交到 Git：`5efae70`。
- [x] 协议与内核：扩展 format/outline 能力，增加格式化派发；文本编码覆盖 UTF-8/BOM、UTF-16 LE/BE、GBK、GB18030、Shift-JIS、Big5、Windows-1252，拒绝无法表示的保存。增加重新解码和带编码保存入口。
- [x] 格式插件：显式注册常用脚本和代码后缀；JSON 格式化在 JSON 插件；代码/HTML/Markdown 格式化适配声明在相应插件。Office 使用现有 OOXML 读取并补充成熟的 DOC/XLS 读取库。
- [x] 公共 UI：接入离线 CodeMirror 和 Prettier；编辑菜单提供格式化、替换/全部替换；视图提供行号、自动换行及二进制入口；文件栏提供当前解码和保存编码、LF/CRLF/CR。
- [x] 每个文件保留正常查看标签；二进制查看使用独立只读标签，避免丢失草稿。不同标签保留各自编辑器历史与阅读位置。
- [x] 验证：新增无损编解码/格式派发/Office 默认识别测试；运行 `node --test app/ui-tests/*.test.mjs`、`cargo test --workspace --offline`；浏览器及原生 WebView2 验证菜单、替换、格式化、保存字节和 Office 内容。
- [x] 发布：生成并核验 Windows 安装包与便携 ZIP。

重点回归：非法编码选择不替换当前文档；格式化失败不改变草稿；异步格式化期间切换标签或继续输入不覆盖新文本；编码转换不绕过格式校验；旧 Office 加密/损坏文件明确报错且二进制入口可用。
