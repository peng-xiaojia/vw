# HTML 原页展示与多文档标签实现计划

**目标：** 保留 HTML 的原始布局和本地资源；多个文件同时打开，草稿和阅读状态独立。

**架构：** 每个标签拥有现有 DocumentController，工作区控制器只负责切换、去重及关闭保护。HTML 使用独立自定义协议挂载已打开文件所在目录，在无同源权限的 sandbox iframe 中渲染原文，与应用 CSS/IPC 隔离。

- [x] 增加标签控制器测试：切换保留草稿、重复路径激活、关闭取消/保存、异步打开与关闭竞态；退出等待后台保存时冻结其他标签编辑。
- [x] 增加 HTML 资源协议测试：CSS/图片、草稿版本逆序、GBK/UTF-16 编码、目录逃逸与句柄关闭失效。
- [x] 实现标签控制器、标签栏、多文件选择、Ctrl+Tab / Ctrl+W、逐文档关闭保护。
- [x] 实现 HTML 独立页面、本地资源读取与严格 CSP、保留 CSS/图片/脚本交互及 iframe 缩放；外链通过应用内显式按钮打开。
- [x] 浏览器对比用户提供的真实 HTML：同内容宽度检查卡片布局、颜色、图片及子页面导航。
- [x] 验证前端与 Rust 工作区、更新能力文档并构建新的 Windows 包。
